# Alexandros Dimitrios Tsolakos - profile site

Bilingual (English / Greek) personal site for the course assignment "Δικτυακός Προγραμματισμός - Εργασία HTML".
Built with HTML, CSS (Bootstrap, custom `styles.css`) and JavaScript; the contact form uses Netlify Forms.

- Live site: https://alexandros-tsolakos.netlify.app/
- Pages: `index.html` (EN), `index.el.html` (GR), `projects.html`, `projects.el.html`, `404.html`
- Custom code: `assets/css/styles.css`, `assets/js/contact.js` (form validation), `assets/js/extras.js` (welcome screen, animations)
- Based on the iPortfolio template by BootstrapMade.

- Extras: `netlify.toml` (headers, `/el` and `/cv` redirects), JSON-LD structured data, WebP images, print-friendly CV (Print CV button), telemetry readout on the rocket bar.
